# MACS Digital Employee Funnel

A mobile-first Next.js 15 single-page sales funnel with Framer Motion, for MACS Digital Media.

## Run locally

```bash
npm install
npm run dev
npm run build
```

## What's included

- Plain-English explanation of what a digital employee does for a busy founder
- Interactive inquiry, follow-up, and admin scenarios
- Ten numbered editorial sections, pricing, FAQ, and consultation CTAs
- Cobalt, navy, and ice-blue visual system
- Mobile navigation, accessible buttons, native scroll, and reduced-motion support

## Sales and capability boundaries

- Starting setup: $1,950 USD, based on owner-provided pricing.
- Monthly care and provider/integration fees are not yet settled.
- Example scenarios are illustrations, not verified live digital-employee actions.
- The primary CTA opens https://www.macsdigitalmedia.com/. The actual MACS lead capture and booking path remains unverified.
- A Picsum image is labeled as an editorial placeholder. Replace it with licensed/original imagery before production.
- No client secrets or credentials are bundled.
